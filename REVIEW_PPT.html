⚠️ Problem Statement

🚨 Critical Issue: Hospitals follow First-Come-First-Served (FCFS) — a heart attack patient may wait behind a routine check-up patient!
❌ Long waiting times — patients wait 2–4 hours with no information
❌ No emergency prioritization — critical cases not identified automatically
❌ No real-time updates — patients don't know their queue position
❌ Doctor schedules not optimized — some doctors idle, others overloaded
❌ No wait time prediction — patients anxious with no estimate
❌ Admin has no live visibility — cannot monitor hospital efficiency

🎯 Goal: Build an AI system that intelligently manages hospital queues,
predicts wait times, and prioritizes emergencies — automatically.

🎯 Objectives

⏱️ Reduce Wait Time

Minimize patient waiting using AI-optimized queue and smart slot scheduling

🚨 Emergency Priority

Automatically detect and prioritize critical patients using AI triage scoring

🤖 ML Prediction

Predict waiting time accurately using Random Forest trained on 30,000 records

📡 Real-Time Updates

WebSocket push notifications — patient gets instant queue position updates

🩺 Optimize Doctors

AI-based appointment scheduler balances load across all available doctors

📊 Admin Analytics

Live dashboard with charts showing hospital performance and efficiency

🤖 AI / ML Features

🚨 Layer 1 — Emergency Triage AI

Rule-based ESI Scoring: 9 symptoms (chest pain, breathing difficulty, stroke...) + 4 vitals (HR, SpO2, Temp, Pain scale) → Score 0–100
Decision Tree Classifier trained on 5,000 synthetic records
Takes MORE CONSERVATIVE of both → CRITICAL / HIGH / MEDIUM / NORMAL
Critical → Auto queue position #1 + Emergency broadcast via WebSocket

⏱️ Layer 2 — Wait Time Prediction (ML)

Algorithm: Random Forest Regressor
Training data: 30,000 synthetic hospital records
Result: MAE = 5.83 minutes (vs 20–30 min error in formula)
Features: Queue position, waiting count, avg consultation time, hour of day, day of week, priority score, doctor count
